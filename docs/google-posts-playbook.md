# Google Posts Playbook (NaqiJo)

Practical, ready-to-publish concepts for the Google Business Profile "Posts"
feature. All copy is built **only** from real website content — no promotions,
prices, discounts, offers, dates, warranties, or availability claims. Rotate
roughly one post every few days; recycle evergreen ones.

**Global rules:** no invented offers/prices; each post links to a real page on
`https://www.naqijo.com`; CTAs use GBP's built-in buttons ("Learn more",
"Call now"). Photos must be real business assets (see the photo guide) — the
"suggested visual" is a description, not a stock mandate.
